# 素材扩展提示词基准

本包使用内置图像生成/编辑流程，并以已有六元素药水瓶作为线条和配色参考，以工位玻璃球效果图作为场景构图参考。

## 固定画风描述

`cute healing Japanese picture-book game illustration, soft pastel cream, warm wood, pale blue and moss green, rounded readable silhouettes, delicate warm brown hand-painted outlines, subtle watercolor texture, soft diffuse daylight, no text, no watermark`

## 透明素材追加规则

`one centered isolated asset, complete object visible, genuine transparent alpha background, no checkerboard, no cast shadow, no scene, no text, square canvas`

## 天气模块模板

`modular transparent Unity 2D weather VFX overlay; keep all graphics inside the same invisible central circular region occupying about 78% of the canvas; leave the lower center readable for the plant; no terrarium, soil or plant`

## 植物模板

`transparent Unity 2D plant-growth sprite; front view; grows directly from a small soil patch; same lighting and hand-painted outline as the terrarium; no pot, glass, weather or UI`

## UI模板

`production-ready transparent Unity 2D UI sprite; warm cream and caramel brown; rounded flat orthographic component; uniform border; blank center; no baked-in words or numbers`

新增素材时始终同时上传六元素药水瓶参考图，避免后续图标逐渐偏离现有画风。
